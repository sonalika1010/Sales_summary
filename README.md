Task 7: Basic Sales Summary Using SQLite and Python
📌 Objective
Use SQL inside Python to analyze sales data by summarizing total quantity sold and total revenue by product. Display results using print statements and a simple bar chart.

🛠 Tools Used
Python
SQLite (built-in via sqlite3)
pandas
matplotlib
📁 Dataset
A small SQLite database file named sales_data.db containing one table: sales.

🧠 What This Task Demonstrates
Writing SQL queries inside Python
Using pandas to load SQL results into a DataFrame
Printing tabular summaries
Creating basic bar charts with matplotlib
📂 Files Included
sales_data.db: SQLite database with sample sales data
sales_summary.py: Python script that performs the analysis
sales_chart.png: Bar chart showing revenue by product
